# Proposal: Add Narrow-Screen Toolbar Mode

## Why

当前响应式设计在屏幕宽度不足时（< 1024px）会自动切换为上下布局，但工具栏没有针对窄屏进行优化：
- 工具栏控件在窄屏下会换行堆叠，占用过多垂直空间
- 主工作流控件（编辑、预览、导出）与次要控件（GitHub、Star、语言）混杂
- 用户在窄屏下难以快速找到核心操作

需要设计一个适合窄屏的工具栏模式，优化垂直空间利用和操作效率。

## What Changes

1. **窄屏工具栏模式**：当屏幕宽度 < 1024px 时，工具栏切换为紧凑布局
2. **主操作优先显示**：仅保留核心控件（字体选择、视图模式、生成DOCX），次要控件收纳
3. **折叠式菜单**：将次要控件（GitHub、Star、语言切换）收入可展开菜单
4. **固定底部操作栏**（可选）：在极窄屏幕（< 480px）下考虑将核心操作固定在底部

## Capabilities

### New Capabilities

- **窄屏工具栏模式**：当 `window.innerWidth < 1024px` 时启用紧凑工具栏布局
- **控件折叠菜单**：次要控件收纳到"更多"菜单中
- **极窄屏底部栏**（可选）：在极窄屏幕下提供更便捷的操作访问

### Modified Capabilities

- **workspace-layout**：更新现有响应式规则，支持窄屏专用模式

## Impact

- 修改 `styles.css`：新增窄屏媒体查询规则
- 修改 `index.html`：如需添加折叠菜单结构
- 修改 `app.js`：添加窄屏模式检测和菜单交互逻辑
- 可能需要更新 i18n 字符串（如有新增 UI 文本）
